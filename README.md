## Puzzle Submitter

<img align="right" width="280" src="https://github.com/baptistecottier/puzzle-submitter-vscode/raw/HEAD/media/demo.gif" alt="Puzzle Submitter sidebar panel and Puzzles tree">

Inputs are fetched, solutions run and answers submitted without leaving VS Code, with
[Puzzle Submitter](https://marketplace.visualstudio.com/items?itemName=baptistecottier.puzzle-submitter),
a free extension by the author of this repository.

- **Five sites**: Advent of Code, Everybody Codes, Codyssi, i18n-puzzles and Coding Quest.
- **No typing**: the puzzle is detected from the file you have open.
- **Inputs cached, answers submitted** for Advent of Code and Everybody Codes; copied to
  the clipboard for the other sites.
- **Python runs as is**: define `solver(data)`, and optionally `preprocessing(data)`, like
  every solution here. Any other language works through a run command.
- **No wasted attempt**: an answer that contradicts a confirmed one asks before being sent.

[Install from the Marketplace](https://marketplace.visualstudio.com/items?itemName=baptistecottier.puzzle-submitter)
· [Source on GitHub](https://github.com/baptistecottier/puzzle-submitter-vscode)
